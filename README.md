# precision-clock

네트워크 시각 API로 보정한 시계, 스톱워치, 타이머를 한 화면에 묶은 정적 웹 도구입니다. 한국어, English, 日本語, 中文을 지원하고 GitHub Pages에서 그대로 동작합니다.

- **시계**: 시각을 소수점 아래 0~3자리(ms)까지 골라 표시하고(버림, 선택값 저장), GPS 위치로 시간대를 정합니다. 위치를 쓰지 않으면 기기 시간대를 씁니다. 시간대 조회 API가 실패하면 GPS 경도(15°당 1시간)로 `Etc/GMT±N`을 계산해 "근사"라고 표시합니다(국경·서머타임은 반영하지 않음).
- **스톱워치 / 타이머**: 스페이스바 또는 마우스를 누르는 순간(`keydown`, `pointerdown`)에 시작·정지합니다. 시각은 이벤트가 만들어진 시점의 타임스탬프(`event.timeStamp`)로 잡아, 화면 갱신 지연이 기록에 들어가지 않습니다. 타이머 알람은 오디오 클록에 미리 예약해 프레임 지연과 무관하게 울립니다.
- 화면에는 시계·스톱워치·타이머 중 하나만 크게 표시하고, 위쪽 탭(또는 `←` `→`, `1`~`3`)으로 전환합니다. 오른쪽 위 버튼으로 브라우저 전체화면을 켭니다.
- 다크 모드: 기기의 라이트/다크 설정을 자동으로 따라갑니다(설정이 바뀌면 즉시 반영).
- 단축키: `Space` 시작/정지, `L` 구간 기록, `R` 초기화

## 시각 보정 방식

모든 샘플은 "서버가 시각을 찍은 순간은 요청을 보낸 시각과 응답을 받은 시각 사이"라는 사실에서 나오는 **오차 구간**입니다. 여러 샘플과 소스의 구간을 교집합으로 좁혀 가며, 화면에 표시되는 `오차 범위`는 그 구간의 반폭입니다.

| 소스 | 해상도 | 사용법 |
| --- | --- | --- |
| [timeapi.io](https://timeapi.io) | 0.1 µs 표기 | 왕복 지연 보정(NTP 방식) 10회 |
| 이 사이트의 HTTP `Date` 헤더 | 1 s | 서버 시각이 초 경계에 닿도록 요청 시점을 맞춰 구간을 이분 탐색 (왕복이 짧아 수 ms까지 좁혀짐) |

30초마다, 탭이 다시 보일 때마다 재동기화합니다.

## 정확도의 한계

- **0.1 ms 이내는 보장할 수 없습니다.** 브라우저에서 인터넷으로 맞추는 시각의 불확실도는 왕복 지연(보통 수 ms~수십 ms)이 하한입니다. 화면에는 추정이 아니라 위 방식으로 계산한 구간이 표시됩니다.
- 웹의 Geolocation API는 위치만 주고 GPS 위성 시각은 주지 않습니다. 그래서 GPS는 시간대 결정에만 씁니다.
- `performance.now()` 해상도는 브라우저가 제한합니다(Chrome 약 0.1 ms, Firefox는 기본 1 ms, 개인정보 보호 설정에서는 더 거칠어집니다).
- 마우스·키보드 이벤트 자체에도 운영체제와 입력 장치의 지연이 있어, 이 앱이 줄일 수 없습니다.

## 개발

```
python -m http.server     # 로컬 확인 (Date 헤더 보정은 http(s)로 열었을 때만 동작)
```
